# My-Python-Learning-Journey

> 我的 Python 学习之旅 —— 从第一个程序开始，记录每一次动手实践的痕迹。

## 一、项目简介

本项目是我在《Python 语言》课程学习过程中建立的个人代码仓库，用于存放课堂练习和自主编写的程序。项目从最基础的输入输出入手，通过一个个小而完整的功能，帮助我熟悉 Python 的语法、交互方式和基本运算逻辑。

目前项目主要解决两个入门问题：

- **学会与程序对话**：通过控制台输入姓名并输出个性化问候，理解 `input()` 与 `print()` 的交互机制。
- **完成简单数值计算**：输入两个数字，自动计算它们的和与差，理解变量、数据类型转换与运算符的使用。

程序规模不大，但每个都有明确的功能目标，是后续学习更复杂项目的基础。

## 二、文件说明

| 文件名 | 类型 | 用途 |

| `calculator.py` | Python 源程序 | 简单计算器：接收两个数字，输出它们的和与差，练习数值输入、类型转换与算术运算。 |

## 三、代码说明

### 1. hello.py —— 输入输出与字符串拼接

核心代码如下：

```python
name = input("请输入你的名字：")
print("你好，" + name + "！")
```

- `input()` 从键盘读取用户输入，返回字符串并赋值给变量 `name`。
- `print()` 中用 `+` 将字符串与变量拼接后输出，实现个性化问候。

### 2. calculator.py —— 数值输入与类型转换

核心代码如下：

```python
a = float(input("请输入第一个数字："))
b = float(input("请输入第二个数字："))
print("两个数字的和是：", a + b)
print("两个数字的差是：", a - b)
```

- `input()` 读入的是字符串，用 `float()` 转换为浮点数，才能参与数学运算。
- 通过 `+`、`-` 运算符计算两数的和与差，并用 `print()` 输出结果。

> 小结：两个程序共同体现了 Python 入门的核心思路——**输入 → 处理 → 输出**。

## 四、学习心得与规划

在 GitHub 上浏览其他同学的 Python 项目时，我发现优秀的项目往往不是代码有多难，而是结构清晰、说明完整：一个规范的 README 就能让别人快速看懂项目在做什么、怎么用。这让我意识到，写好说明和写好代码同样重要。

完成这次任务的过程中，我第一次完整经历了"本地编写 → Git 提交 → 推送到远程仓库"的流程。把文件真正 push 上去、看到两次提交记录、确认链接可以在任意设备上打开时，我感受到了把个人项目公开管理的成就感，也明白了版本记录对追踪学习过程的意义。

对我而言，管理个人项目和展示技能的关键，是让成果**可见、可查、可持续**。 GitHub 仓库正好提供了这样一个窗口：代码、说明和更新记录都集中在一起，别人点开链接就能看到我的成长轨迹。

未来我计划这样使用这个仓库：每学完一个知识点就补充一个小程序或笔记，一次学习对应一次提交，让提交信息成为学习日志；逐步完善 README，按主题整理文件目录；同时坚持在"学习心得与规划"中记录每次的收获与不足。希望若干年后回看，这个仓库能清楚地记录我从入门到熟练的每一步。
